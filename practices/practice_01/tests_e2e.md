# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный — корректный дифф | Доступен POST `/api/reviews` | Отправить тело `{"diff": "small valid diff"}` | Ответ содержит `summary`, `risks` (≤ 3, с полями), `checks` (OUT-1) | review_service.py:17 → api.py:9 — сейчас `{ "comment": ... }` |
| Негативный — невалидное тело | Доступен POST `/api/reviews` | Отправить тело `{}` без ключа `diff` | 4xx (400/422), а не 5xx | api.py:9 — сейчас `payload["diff"]` может вызвать 5xx |
| Граничный — очень длинный дифф | Доступен POST `/api/reviews` | Отправить `diff` длиной > 20000 символов | HTTP 413, LLM не вызывается (API-1) | api.py:9 — отсутствует проверка длины |
