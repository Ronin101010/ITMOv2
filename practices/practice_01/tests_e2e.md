| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный — корректный дифф | Доступен POST `/api/reviews` | Отправить тело `{"diff": "small valid diff"}` | Ответ содержит строго поля `summary`, `risks` (≤ 3, элементы имеют `file,line,evidence,risk`), `checks`; лишних полей нет (OUT-1) | review_service.py:17 → api.py:9 — сейчас `{ "comment": ... }` |
| Негативный — невалидное тело | Доступен POST `/api/reviews` | Отправить тело `{}` без ключа `diff` | 4xx (400/422), а не 5xx | api.py:9 — сейчас `payload["diff"]` может вызвать 5xx |
| Граничный — ровно 20000 символов | Доступен POST `/api/reviews` | Отправить `diff` длиной == 20000 символов | HTTP 200; LLM вызывается; ответ по OUT-1 | API-1 — 413 только при `> 20000` |
| Негативный — очень длинный дифф | Доступен POST `/api/reviews` | Отправить `diff` длиной > 20000 символов | HTTP 413; вызова LLM нет (API-1) | api.py:9 — отсутствует проверка длины |
