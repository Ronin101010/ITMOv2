# Skill: test-driven-development

Описание
- Использовать TDD для маленьких фич A/B: сначала написать падающий тест, затем реализация, затем рефакторинг.

Быстрые инструкции
- Напиши тест для ожидаемого поведения.
- Запусти проверки (ожидаем падение).
- Исправь реализацию.
- Подтверди, что тесты проходят.
